Open-source project · Android TV + Windows

Miracast
AutoConnect

Trigger a wireless display connection from Android TV to a Windows PC—with a background listener and Windows Runtime projection APIs, without opening the Win+K flyout or automating keyboard and mouse input.

View source on GitHub Quick-start guide Report an issue

Background connection

A Windows PowerShell listener receives a local UDP trigger and requests projection through the Windows Runtime ProjectionManager API.

Android TV trigger

The Android TV app launches the available receiver/settings activity and sends a trigger over the local network.

No UI automation

The project is designed to avoid the Win+K flyout and simulated keyboard or mouse interaction with Windows UI.

How it works

  1. Put the TV into its Miracast receiver or waiting mode.
  2. Launch Miracast AutoConnect on Android TV, or use a configured remote-button trigger.
  3. The app sends a local-network UDP message to the Windows listener on port 8888.
  4. The listener searches for the configured display and requests wireless projection.
  5. Confirm that the TV displays the Windows desktop; a trigger or API response alone does not prove mirroring is active.

Verified end-to-end setup

The maintainer has verified actual desktop mirroring on a Xiaomi TV A 65 (2025), running Windows 11 Home build 26300 with a Realtek RTL8852BE Wi-Fi adapter. The background listener and automatic trigger workflow continued working after reboot.

Requirements

Windows 10/11 with wireless projection support, Windows PowerShell 5.1, a compatible Wi-Fi adapter and driver, and a TV firmware that provides a compatible Miracast receiver.
