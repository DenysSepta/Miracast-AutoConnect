Miracast AutoConnect

Connect an Android TV Miracast receiver to a Windows PC automatically — without opening the Win+K flyout, pressing Win+P, or automating keyboard and mouse input.

View source on GitHub Installation guide Report an issue
Verified end-to-end: the maintainer has confirmed actual Windows desktop mirroring to a Xiaomi TV A 65 (2025), running Windows 11 Home build 26300 with a Realtek RTL8852BE Wi-Fi adapter. The background listener and trigger workflow continued working after reboot.

What it does

Background connection

A Windows PowerShell listener receives a local-network trigger and asks Windows to start wireless projection through the Windows Runtime ProjectionManager API.

Android TV trigger

The Android TV app opens the available receiver activity and sends a UDP trigger over the local network.

No UI automation

The workflow does not open the Windows Win+K or Win+P panels and does not depend on simulated keyboard or mouse input.

How it works

  1. Put the television in its Miracast receiver or waiting mode.
  2. Launch Miracast AutoConnect on Android TV, or use a supported remote-button mapping.
  3. The app sends a local UDP trigger to the Windows listener (port 8888 by default).
  4. The listener uses Windows ProjectionManager to discover the configured wireless display and request projection.
  5. Confirm that the desktop is actually visible on the television.

A successful trigger or API call alone is not proof of mirroring; the TV screen must be checked. Hardware, driver, receiver firmware, and network configuration can affect discovery and connection.

Requirements

  • Android TV / Google TV running Android 10 (API 29) or later, with a compatible Miracast receiver.
  • Windows 10 or Windows 11 with wireless projection support and a compatible Wi-Fi adapter/driver.
  • Windows PowerShell 5.1 for the supplied listener.
  • The TV and PC on a local network that permits the trigger traffic; the TV must be awake and waiting for Miracast.

Get started

The repository contains the Android app source, the Windows PowerShell listener, diagnostics, and setup documentation. Build and install the Android app, run the Windows diagnostic command, then install the optional logon task for background listening.
